# 모형 문서 v0.1 (계산 순서)

연간, t = 2025(보정)…2050, 단위 조원·TWh·Mt. 기호는 `model.ts` 변수명과 같다. [ ]는 계보.

## 0. 개시 스톡(2024말)과 보정(2025)
- 은행 대차가 닫히도록 예금 총액을 푼다: D = (L_nfc + L_ps + L_h − E_bk − Adv)/(1 − bb − rr). 가계 예금은 잔차, 외환보유액 FXR = 현금 + 지준 − Adv − B_cb.
- 2025년은 지출 구성을 국민계정 비율로 고정해 한 번 풀고, 다음을 보정한다: 소비성향 α1(2026 소비가 명목성장률로 늘도록), 자본 순증가율 gK0, 가동률 기준 u0와 자본계수, 이윤율·DSR·BIS비율·실질금리 기준값, 신용할당 절편(CR0 = 5%), 녹색비중 절편, 비전력 배출 원단위, 전력부문 임금·중간투입(2025 요금이 원가를 회수하도록), 수입성향.
- 보정은 설정(시나리오·규칙·설계)과 무관하게 같은 값이 나오도록 메가프로젝트·K-GX 흐름이 2026부터 시작한다.

## 1. 외생 경로
환율 지수(충격 기간 1 + fx_shock), 수입연료 가격지수 = gas_shock × 환율 × 세계물가, 메가프로젝트 GW(2026 2.5 → 2029 8.4 → 2035 18.4, 11차 전기본 내재분 + 1.8GW 차감, 실현율), 재생 계획(39 → 78(2030) → 121.9GW(2038), K-GX 100GW 스위치), K-GX 재정 단계(2026–35 체증 가중), 세액공제 일정(2027–36, 2034 75%·2035 50%·2036 25%), 정책금융(2026 56.7조에서 선형 체증, 10년 합 790조).

## 2. 정책금리 (전기 값 사용) [DEF 427 / MFM / 자체 AIT]
- define: ln r_t = ln r_{t−1} + ε(α ln INF_{t−1} − ln r_{t−1}) (%, INF ≥ 0.1)
- taylorH/C: i = ρ i₋₁ + (1−ρ)[r* + π* + φπ(π₋₁ − π*) + φy·gap₋₁], H = 헤드라인, C = 근원
- ait: 위 식에서 물가갭 대신 band(h년 평균 헤드라인 − π*), band(x) = sgn(x)·max(0, |x| − b)
- fixed: i0. 모든 규칙에 외생 이동 di_exo를 더하고 0에서 하한.

## 3. 금리
rD = i − sD, r_c = i + sL + χ·gdcr, r_g = i + sL − χ·gdcr, r_h = i + sLh, i_B = i_B₋₁ + κB(i + tp + prem − i_B₋₁),
prem = prem_on·μ1·max(0, (B + α_off·장부밖)/Y₋₁ − 기준) [MFM; Canelli 2024 계수], r_ps = i_B + s_ps, r_PBL = i_B + pf_spread, r_PBB = i_B + pbb_spread.

## 4. 물가 [MFM 필립스 축약, DEF 56–58]
π^e = λπ* + (1−λ)π^H₋₁; 근원 π^C = π^e + κu(u₋₁ − u0) + io_el(π^el₋₁ − π*) + io_fu(π^fu₋₁ − π*) + θfx·Δe;
P = P₋₁(1 + π^C); 소비자 연료 π^fu = π* + θfu·Δ(연료지수); 헤드라인 π^H = (1 − w_el − w_fu)π^C + w_el π^el + w_fu π^fu.

## 5. 전력 [L1, MFE, GMM, DEF 89–91·109]
- 재생 WACC w_RE = w0 + β(i − i0) + rp_design − conc(K-GX 정책대출 금리우대) ; ΔLCOE_g = s_K[CRF(w_RE,22)/CRF(w0,22) − 1] − s_K·(전력 보조금/계획 capex)
- 재생 설치 = 계획 증분 × clamp(1 − ε·ΔLCOE_g, 0, re_cap_x). 부족분은 기준 계통의 가스가 메운다(2차 배출).
- 증분 발전 = GW × 부하율 × 8.76 × 1.03. 시나리오별 기술 비중(G 가스 100%, R 태양광·육상·해상 + 가스 보강 φ, M 혼합, N 2033~ 원전 90%). endo_mix: VRE 비중 = (1−φ)·Λ(b0 + b1·(LCOE_gas − LCOE_RE)/LCOE_gas·100 − 설계위험).
- GMMET형 간헐성: φ_t = φ0 + s_φ(VRE²₋₁ − VRE²₂₀₂₅), 저장비율도 같은 형태.
- 설비는 누적 최대치로 짓고(매몰), capex는 수입분(mimp_k)과 국내분으로 나뉜다. 연금 = capex·(CRF(w, n) + FOM), 연료 = TWh·3.6/η·가스가격.
- 요금: 원가요금 T* = (연료 + 배출권 + 중간투입 + 임금 + 이자 + 감가상각 − DC 부담)/일반 판매량.
  admin: 시차 L, 묶음 주기, 전가율 ρ, 래칫. cfd: T = T*₋₁. pool: P^ELEC = P^min + (P^max − P^min)(1 − β^NFF)^μ + 망비용.
  DC 부담 = (1 − σ)·증분 경제비용(연금 + 연료 + 배출권 + 워터베드 매입), pool에서는 시장가 × 부하. 지역요금제 경감(2.8조/년, 2027~)은 전력부문 흡수/재정보전/교차보조 선택.

## 6. K-ETS와 갭 해소 [L1 D10·D18–D20]
KAU = kau2026(1 + g)^{t−2026}·P, 상한 kau_ceiling·P. 경직(ets_mode=1): KAU += ΔE/기울기, 타 업체 감축 E_w(평균가 비용), 전력부문이 E_w × KAU를 산업에 지급, 상한을 넘는 몫은 누출. 수용(0): 갭 = ΔE → ITMO(상한 itmo_cap, 정부 → 해외) 또는 국내 감축(비용 = 물량 × MAC_dom, 정부 보조 γ = 1 − KAU/MAC).

## 7. K-GX
재정: 기업 보조(자본이전), 전력 보조, R&D(정부소비), 세액공제(법인세 차감, 비환급), 이차보전(정부 → 정책금융, 차입자 금리 차감), 출자(자본이전), 공공 녹색투자. 하이브리드: 세액공제 절반을 2027–29 선지급 보조로.
정책금융: 대출(만기 상환, 기대손실 상각), 출자(손실 상각), 보증(장부 밖 잔액, 보증료, 대위변제 = 정책금융 → 은행, 같은 액수의 대출 상각). 정책금융채는 은행 보유, PBB = 자산 − 자본.
추가성: 추가 녹색투자 = add_pf(대출+출자) + add_guar·보증 + add_grant·보조 + add_ptc·공제 + add_priv·민간 시그니처.

## 8. 지출과 GDP
C = α1·YD₋₁(1 + π^e + g*) + α2·NFW_HH₋₁; G = (g + drift·t)Y₋₁(1 + π^e + g*)(1 − cut) + R&D; 투자 I_nfc = P(gK + δ)K₋₁(1 − CR)/(1 − CR0) + 추가성 + 감축 capex,
gK = gK0 + a_u(u₋₁ − u0) + a_p(rp₋₁ − rp0) − a_r(rr − rr0) [DEF 183, SFF 62]; CR = CR_max/(1 + e^{c0 − r2·DSR₋₁ + r3(CAR₋₁ − CAR0)}) [DEF 225];
녹색비중 β = Λ(z0 + b_τ·KAU실질 + b_r(r_c − r_g)100 + b_trend·t) [DEF 185, SFF 70]; X = X₋₁(1 + g_w)(1 + ε_x Δe) + dc_rev·DC 부담; M = m(C_ne + G + I_nfc + I_gov) + 0.22X + 비전력 에너지 + 발전연료 + 전력 capex 수입분; Y = C + G + I + X − M.
재정준칙: cut = min(0.5, κ_f·max(0, B/Y₋₁ − d*)/g). 1 = 녹색 포함 삭감, 2 = 녹색 보호.

## 9. 분배·원장
모든 거래는 (지급 부문, 수취 부문, 금액) 한 줄로 기록되어 행 합이 0이다. 순대출은 원장에서 계산한다. 이자는 기초 잔액 × 당기 금리, 배당은 세후이익의 일정 비율, 한은 이익은 전액 정부.

## 10. 금융 스톡(행태 + 잔차)
가계: 현금 = c·C, 국채 = λ(FA − 현금), λ = λ0 + λ1·(i_B − rD 차이), 예금 = 잔차. 기업: 예금 ∝ Y, 은행대출 = 잔차. 전력부문: 차입 = 잔차(요금 이연이 여기로). 정부: B = B₋₁ − NL. 해외: 국채 = b_row·B, 예금 = 잔차. 은행: 지준 rr·D, 국채 bb·D, 한은 대출 = 잔차. 한은: 국채 = 현금 + 지준 − 대출 − FXR(잔차). 잉여식 B = ΣB_i는 검사만.

## 11. 실물·생태 [SFF 55–57, DEF 26]
K = (1 − δ − d_K)K₋₁ + I/P, u = Y_R/[(K_nfc + K_gov)/v · (1 + g_prod)^t · (1 − 생산성 피해)] (전력자본은 분모에서 제외 [MFE]).
피해: D_T = 1 − 1/(1 + η2T² + η3T^6.754)(2025 대비 증분), D_TP = pD_T, D_TF = 1 − (1 − D_T)/(1 − D_TP), d_K = (1 − adK)D_TF.
비전력 배출 원단위 ω = ω₋₁(1 − em_decay − em_green·Δθ_K); 국가 배출 = 전력 + ω·Y_R − 워터베드 감축 − 국내 감축. NDC 경로: 2030 445.4(2006GL 환산), 2035 −53%, 2040 −69%, 2045 −84%, 2050 0.

## 12. 귀착 (Q1)
증분 자원비용 = 설비·계통 연금 + 연료 + 워터베드 감축비용 + 국내 감축비용 + ITMO(배출권 대금·경매 등 이전 제외).
귀착은 '같은 설정 + 메가프로젝트 없음' 대비 누적: DC 전용요금, 일반 요금(가계+기업), 전력부문 부채(잔액), 재정 직접지출, 정부 순차입, ETS 기업 순부담, 국내감축 자부담.

## 13. 알려진 한계
- 보정이 등급 C(초기 스톡, 행태계수). 기준선 비전력 배출은 NDC 경로보다 높다(연구 설계상 K-GX 기준선은 고정하고 증분만 해석).
- 메가프로젝트 자체 투자·산출은 범위 밖(DC 전기요금은 기본적으로 DC 서비스 매출로 충당, `dc_rev`).
- 환율은 외생 충격, 주식·주택·NMFI 없음, 분기 → 연간, 원 모형 대비 식이 축약됨.
- 시장설계 위험프리미엄, 추가성 계수, K-GX 배분은 근거 없는 자리표시자.
